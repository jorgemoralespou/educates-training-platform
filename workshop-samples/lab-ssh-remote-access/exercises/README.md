Exercise files for the SSH remote access test workshop.

* `python-client/tunnel.py` — Python reference SSH `ProxyCommand` tunnel client.
* `go-client/` — Go reference SSH `ProxyCommand` tunnel client (for reference).

The Educates CLI (used as the other tunnel client) is not stored here — it is
downloaded into `~/bin` at session start by `workshop/setup.d/01-download-educates-cli.sh`.
