---
title: Downloading Directory Archives
---

When `vendir` populated the assets server it unpacked the source archive into
individual files, so there is no single archive to download. To get a whole
directory back as one file, the assets server can generate an archive on the fly
when you request a directory path with an archive extension suffix.

You will download the `project-docs` directory from the unpacked source in each
of the supported archive formats and inspect the result. The terminal starts in
the `~/exercises` directory, so each archive is saved there.

## gzip-compressed tar archive

Request the directory with a `/.tar.gz` suffix:

```terminal:execute
command: |-
  curl -fsS -o educates-docs.tar.gz {{< param ingress_protocol >}}://{{< param assets_repository >}}/educates-source/educates-training-platform-develop/project-docs/.tar.gz
```

List the archive contents to confirm it contains the documentation files:

```terminal:execute
command: tar -tzf educates-docs.tar.gz | head -20
```

The `/.tgz` suffix is an alias for `/.tar.gz` and produces the same result.

## Uncompressed tar archive

Request the same directory with a `/.tar` suffix:

```terminal:execute
command: |-
  curl -fsS -o educates-docs.tar {{< param ingress_protocol >}}://{{< param assets_repository >}}/educates-source/educates-training-platform-develop/project-docs/.tar
```

List the contents of the uncompressed archive:

```terminal:execute
command: tar -tf educates-docs.tar | head -20
```

## zip archive

Request the directory with a `/.zip` suffix:

```terminal:execute
command: |-
  curl -fsS -o educates-docs.zip {{< param ingress_protocol >}}://{{< param assets_repository >}}/educates-source/educates-training-platform-develop/project-docs/.zip
```

List the contents of the zip archive:

```terminal:execute
command: unzip -l educates-docs.zip | head -20
```

Finally, compare the sizes of the three archives. The gzip-compressed `tar` and
the `zip` archive should both be noticeably smaller than the uncompressed `tar`
archive:

```terminal:execute
command: ls -l educates-docs.tar educates-docs.tar.gz educates-docs.zip
```

{{< note >}}
Each of these archives was generated by the assets server at request time from
the directory of individual files it holds. Requesting a path that maps to a
file, rather than a directory, returns the file itself regardless of any
suffix.
{{< /note >}}
